# Запуск на своём компьютере

Для знакомства с ботом и проверки, что всё настроено правильно. Бот работает,
пока включён компьютер и открыто чёрное окно — выключили, и он замолчал.
Для постоянной работы нужен сервер, но начать удобнее так.

Понадобится полчаса, из них двадцать минут компьютер работает сам.

## Что нужно иметь под рукой

Из вашей заметки:

- токен бота от `@BotFather`;
- ваш Telegram ID от `@userinfobot`;
- ключ Anthropic (`sk-ant-...`);
- файл `service-account.json` и ID Google-таблицы.

Битрикс и hh.ru можно пропустить — бот запустится и без них.

## 1. Установить Python

Python — программа, которая умеет запускать наш код. Ставится один раз.

1. Откройте `python.org/downloads`
2. Жёлтая кнопка **Download Python** — версия подойдёт любая от 3.11
3. Запустите скачанный файл
4. **Внизу первого окна поставьте галочку «Add Python to PATH»** — её легко
   пропустить, а без неё ничего не заработает
5. **Install Now**, дождитесь конца, закройте

## 2. Скачать программу

1. Откройте `github.com/u25534630-code/home-accounting/tree/claude/bitrix-nnru-integration-kiz73y`
2. Зелёная кнопка **Code** → **Download ZIP**
3. Распакуйте архив куда удобно, например в «Документы»
4. Зайдите внутрь, в папку **backend**
5. Положите туда файл `service-account.json`

## 3. Запустить

В папке `backend` найдите файл **`start.bat`** и запустите двойным щелчком.

Откроется чёрное окно — это нормально, программы без окошек так и выглядят.

**Первый запуск долгий**, минут десять–пятнадцать: скачиваются библиотеки и
модель распознавания речи. Окно будет что-то писать — пусть пишет. Следующие
запуски занимают секунд двадцать.

Если Windows покажет «Windows защитила ваш компьютер» — **Подробнее** →
**Выполнить в любом случае**. Так бывает со всеми файлами из интернета.

## 4. Ответить на вопросы мастера

Программа сама спросит настройки. Вставляйте значения из заметки.

Вставить в чёрное окно — **правая кнопка мыши**, не Ctrl+V.

Где не подключаете (Битрикс, hh.ru) — просто нажимайте Enter.

На вопрос про **пробный режим отвечайте «д»**. В нём бот всё понимает и
отвечает, но наружу ничего не пишет — можно спокойно пробовать, ничего не
испортив. Выключим потом.

## 5. Проверить

Когда в окне появится `Бот запущен`, откройте Телеграм и напишите своему боту:

```
/start
```

Он должен ответить. Дальше попробуйте:

> Запиши кандидата: Иванова Мария, монтажник, Екатеринбург, телефон 9001234567

Бот покажет, что понял, и спросит подтверждение. Затем:

> Иванова, собес в четверг в 15:00

Проверьте голосом — нажмите микрофон и скажите то же самое. Ради этого всё
и затевалось.

Команды: `/active` — кто в работе, `/today` — сводка за сегодня.

## 6. Остановить

Закройте чёрное окно или нажмите в нём Ctrl+C. Бот замолчит.

Чтобы запустить снова — тот же `start.bat`, теперь уже быстро.

## Если что-то пошло не так

| Что видите | Что делать |
|---|---|
| «Python не найден» | Не поставлена галочка «Add Python to PATH». Переустановите Python, галочку поставьте |
| Окно мигнуло и закрылось | Запустите `start.bat` правой кнопкой → «Изменить», посмотрите, нет ли ошибки. Или откройте командную строку в этой папке и наберите `start.bat` |
| Бот не отвечает на `/start` | Проверьте, что в окне написано `Бот запущен` и нет красных строк. Проверьте, что пишете **своему** боту, а не чужому с похожим именем |
| «Не смог расшифровать голосовое» | Не хватило памяти на модель. Откройте `.env`, поставьте `WHISPER_MODEL=tiny`, перезапустите |
| Долго думает над голосовым | Так и будет на обычном компьютере: 10–30 секунд. На сервере быстрее |

Что бы ни случилось — **испортить данные в пробном режиме нельзя**, наружу
ничего не уходит.

## Что дальше

Понравится — переносим на сервер, там бот работает круглосуточно и не зависит
от вашего компьютера. Всё настроенное переезжает как есть: файл `.env` и
`service-account.json` просто копируются.
