# Доступ к Google-таблице

Боту нужно право писать в таблицу. Живой человек для этого не подходит — нужен
«робот-сотрудник», по-гугловски **сервисный аккаунт**. Это учётная запись без
пароля и почтового ящика, от имени которой программа заходит в таблицу.

Минут пятнадцать. Самое муторное место во всей настройке, зато один раз.

Два шага, которые чаще всего забывают, из-за чего потом ничего не работает:

- **включить Google Sheets API** (шаг 3);
- **поделиться таблицей с сервисным аккаунтом** (шаг 7).

## 0. Чем заходить

Открывайте всё под тем Google-аккаунтом, **из-под которого у вас есть доступ к
таблице на редактирование**. Если таблица чужая, понадобится либо право делиться
ею, либо помощь владельца на шаге 7.

## 1. Создать проект

1. Откройте `console.cloud.google.com`
2. Если просят — согласитесь с условиями, карту привязывать не нужно
3. Вверху слева, рядом с логотипом Google Cloud, нажмите на выпадающий список
   проектов → **NEW PROJECT / СОЗДАТЬ ПРОЕКТ**
4. Название: `Recruiter Bot`. Нажмите **CREATE**
5. Подождите полминуты и убедитесь, что вверху выбран именно этот проект

## 2. Найти нужный раздел

В строке поиска вверху страницы наберите `Google Sheets API` и откройте
результат с таким названием.

## 3. Включить Sheets API

На открывшейся странице нажмите синюю кнопку **ENABLE / ВКЛЮЧИТЬ**.

Если написано **MANAGE / УПРАВЛЯТЬ** — значит уже включено, идём дальше.

Без этого шага бот получит ошибку `SERVICE_DISABLED`.

## 4. Создать сервисный аккаунт

1. В поиске вверху наберите `Service Accounts` и откройте раздел
2. **+ CREATE SERVICE ACCOUNT**
3. Имя: `recruiter-bot`. Поле ID заполнится само
4. **CREATE AND CONTINUE**
5. Шаг «Grant this service account access» — **пропустить**, нажать **CONTINUE**
6. Последний шаг — **DONE**

## 5. Скопировать адрес сервисного аккаунта

В списке появится строка с адресом вида:

```
recruiter-bot@recruiter-bot-123456.iam.gserviceaccount.com
```

Скопируйте его — понадобится на шаге 7. Похож на почту, но письма туда не ходят,
это просто имя робота.

## 6. Скачать ключ

1. Нажмите на созданный сервисный аккаунт
2. Вкладка **KEYS / КЛЮЧИ**
3. **ADD KEY → Create new key**
4. Формат **JSON**, нажать **CREATE**
5. Файл скачается сам, имя вроде `recruiter-bot-123456-a1b2c3d4e5f6.json`

Переименуйте его в `service-account.json` и положите рядом с программой.

**Это пароль от робота.** Не пересылайте его в чаты и не кладите в общие папки.
Скачать повторно нельзя — при потере создаётся новый ключ, старый удаляется.

## 7. Поделиться таблицей

Самый забываемый шаг. Робот создан, но к вашей таблице отношения пока не имеет.

1. Откройте таблицу
   `https://docs.google.com/spreadsheets/d/1ReDh9BElb1VkFuV0j0aVCBkR5UmpHOwIIcAR2xjDjac/`
2. Кнопка **Настройки доступа / Share** справа вверху
3. Вставьте адрес из шага 5
4. Права — **Редактор / Editor**, не «Читатель»
5. Снимите галочку «Уведомить пользователей» — роботу письмо ни к чему
6. **Отправить / Share**

Google может предупредить, что адрес не похож на обычный, — это нормально.

## 8. Проверить названия вкладок

Внизу таблицы, на ярлычках листов, должны быть вкладки
**«отслеживание проходящих»** и **«стажеры»**.

Названия должны совпадать с тем, что записано в `.env`
(`SHEET_TRACKING_NAME`, `SHEET_INTERNS_NAME`). Регистр и лишние пробелы не важны,
а вот другое слово — важно.

Заголовки колонок в первой строке бот разберёт сам: он ищет их по названию и
понимает синонимы («ЗП», «зарплата», «ожидания»). При старте напишет в лог,
какие колонки не нашёл.

## Что должно получиться

| Что | Куда |
|---|---|
| Файл `service-account.json` | рядом с программой, путь в `GOOGLE_CREDENTIALS_FILE` |
| Адрес сервисного аккаунта | добавлен в доступ к таблице как **Редактор** |
| ID таблицы | в `GOOGLE_SPREADSHEET_ID` |

ID таблицы — это часть ссылки между `/d/` и `/edit`:

```
https://docs.google.com/spreadsheets/d/1ReDh9BElb1VkFuV0j0aVCBkR5UmpHOwIIcAR2xjDjac/edit
                                       └──────────────── вот это ────────────────┘
```

## Если что-то пошло не так

| Ошибка | Причина |
|---|---|
| `SERVICE_DISABLED` | не сделан шаг 3 — Sheets API не включён |
| `The caller does not have permission` | не сделан шаг 7 — таблицей не поделились |
| `Unable to parse range` | вкладка называется не так, как в `.env` |
| `File not found` | неверный `GOOGLE_SPREADSHEET_ID` |

Первые две — 90% случаев.
