# Рекрутинговый ассистент

Интеграция Bitrix24, hh.ru, Telegram и Google Sheets для обзвона кандидатов.
Рекрутер после звонка говорит одну фразу — лид в CRM, строка в таблице,
напоминание о собеседовании и дневная статистика делаются сами.

- **Зачем и как выглядит в работе** — [idea.md](idea.md)
- **Что уже сделано и что дальше** — [plan.md](plan.md)
- **Как устроено внутри** — [docs/architecture.md](docs/architecture.md)
- **Запуск** — [backend/README.md](backend/README.md)
- **Настройка Битрикса** — [docs/bitrix_setup.md](docs/bitrix_setup.md)

## Коротко

```
hh.ru (отклики) ──▶ лид в Битриксе ──▶ обзвон ──▶ голосовая команда в ТГ
                                                          │
                            ┌─────────────────────────────┤
                            ▼                             ▼
                   не подходит:                    подходит:
                   лид в «Не подходит»             стадия + Google-таблица
                   с причиной отказа               + напоминания о собесе
                                                          │
                                                          ▼
                                                  прошёл собес:
                                                  вкладка «стажеры»

                            19:00 ──▶ сводка по результативным звонкам
```
