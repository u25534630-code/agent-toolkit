# Структура контента лид-магнита

## Общие принципы

### Ценность на каждой странице
- Каждый раздел должен давать конкретную пользу
- Никакой воды и очевидных истин
- Практика важнее теории

### Язык целевой аудитории
- Писать так, как говорит ЦА
- Избегать сложного жаргона
- Объяснять новые термины сразу

### Визуальная читаемость
- Короткие абзацы (3-4 строки максимум)
- Много списков и пунктов
- Таблицы для сравнений
- Выделения для важного

### Заголовки разделов
- Заголовок `##` — это только название главы: `## Ставим программу`, а не `## Часть 3. Ставим программу`.
- Слово «Часть», «Раздел», «Глава» и порядковый номер в заголовке не пишем: генератор HTML сам печатает надстрочник `РАЗДЕЛ / 03` над каждым `h2`.
- Нумерация шагов инструкции — исключение и норма: `## Шаг 1. Ставим программу`.
- Ссылки внутри текста — по названию главы, не по номеру: «смотрите главу «Если приложение не завелось»».

### Ссылки на названные проекты и сайты
- Если в тексте назван конкретный проект, сайт, сервис, инструмент, конкурент или маркетплейс, первое упоминание должно быть кликабельной markdown-ссылкой: `[Название](https://...)`.
- Ссылка должна вести на официальный сайт или основную страницу продукта, а не на случайную статью.
- Если пользователь просит не уводить трафик на внешние сайты, не добавлять внешние ссылки и явно сохранить это ограничение в логике документа.

## Обязательные элементы

### 1. Обложка (1 страница)
```markdown
# [ЯРКИЙ ЗАГОЛОВОК С ВЫГОДОЙ]

## [Подзаголовок с конкретикой: числа, результат]

[Иллюстрация/изображение по теме]

**Автор:** [Имя]
**Курс/Проект:** [Название]
```

**Примеры заголовков:**
- ❌ "Гайд по нейросетям"
- ✅ "10 AI-инструментов, которые сэкономят вам 20 часов в неделю"
- ❌ "Как создать Telegram-бота"
- ✅ "Доходный Telegram-бот за 3 дня: пошаговое руководство"

---

### 2. Введение (1 страница)
```markdown
## Что вы получите из этого материала

[1-2 абзаца: обещание конкретного результата]

### После изучения вы будете:
- [Конкретный результат 1]
- [Конкретный результат 2]
- [Конкретный результат 3]

### Для кого этот материал:
- [Идеальный читатель 1]
- [Идеальный читатель 2]
- [Идеальный читатель 3]

### Кому этот материал НЕ подойдёт:
- [Антипортрет 1]
```

### 3. Основной контент (80% документа)

#### Формат: Гайд/Руководство
```markdown
## Шаг 1: [Название шага с результатом]

### Что делаем
[Краткое описание задачи]

### Пошаговая инструкция
1. [Действие 1]

   <!-- SCREENSHOT: filename.png — описание что показать -->
   ![Описание](assets/screenshots/filename.png)

2. [Действие 2]
3. [Действие 3]

### Пример
[Конкретный пример выполнения]

### Частые ошибки
- [Ошибка 1] — [почему это плохо]
- [Ошибка 2] — [как избежать]

> **Совет.** [Полезная подсказка]

---
```

#### Формат: Подборка инструментов/Идей
```markdown
## [Название инструмента/идеи]

### Описание
[Первое упоминание инструмента/проекта в формате [Название](https://...) + что это и для чего]

### Для кого подходит
- [Аудитория 1]
- [Аудитория 2]

### Стоимость
- Бесплатно: [что входит]
- Платно: [цена] — [что входит]

### Плюсы
- [Плюс 1]
- [Плюс 2]

### Минусы
- [Минус 1]

### Ссылка
[Название](https://официальный-сайт)

### Вердикт
[Краткий итог]

---
```

Важно: эмодзи в заголовках карточек (📝, 🎯, 💰, ✅, ❌, 🔗, 📊) и в номерах пунктов (`## 1. Lovable`) — **не нужны**. Заголовок должен быть чистым: `## Lovable`, `### Описание`, `### Для кого подходит`.

#### Формат: Чек-лист
```markdown
## [Категория/Раздел]

### [Подкатегория]
- [ ] [Пункт с действием] — [краткое пояснение]
- [ ] [Пункт с действием]
- [ ] [Пункт с действием]

> **Важно.** [Ключевое замечание к этому разделу]

---
```

### 4. Сравнительные таблицы (где уместно)

```markdown
## Сравнение [чего с чем]

| Критерий | [Вариант 1] | [Вариант 2] | [Вариант 3] |
|----------|-------------|-------------|-------------|
| Цена | Бесплатно | $20/мес | $50/мес |
| Сложность | Просто | Средне | Сложно |
| Для кого | Новички | Средний | Профи |
| Результат | Базовый | Хороший | Лучший |

### Рекомендация автора
[Какой вариант выбрать и почему]
```

---

### 5. Блоки-выделения

В callout-блоках **не используем эмодзи** — выделение делает само жирное слово.

```markdown
> **Совет.** [Полезная подсказка]

> **Важно.** [Предупреждение о возможных проблемах]

> **Ключевая мысль.** [Самое важное из раздела]

> **Запомните.** [То, что нужно запомнить]

> **Чек-пойнт.** [Что должно быть сделано к этому моменту]
```

---

### 6. Заключение (1 страница)

```markdown
## Что делать дальше

### Краткий итог
[2-3 предложения: что узнали, какой результат]

### Ваши следующие шаги
1. [Конкретное действие 1]
2. [Конкретное действие 2]
3. [Конкретное действие 3]

### Хотите больше?
[CTA — призыв к действию: записаться на курс, подписаться, и т.д.]

[Кнопка/ссылка на продукт]
```

## Примеры хорошего контента

### Хороший пример описания инструмента:
```markdown
## Cursor — AI-редактор кода

### Описание
Cursor — это VS Code на стероидах. Редактор кода с встроенным AI-ассистентом, который понимает весь ваш проект и может писать, редактировать и объяснять код.

### Для кого подходит
- Разработчики любого уровня
- Вайбкодеры (можно создавать без знания кода)
- Те, кто хочет ускорить написание кода в 5-10 раз

### Бесплатный тариф
Есть — несколько десятков запросов к AI в месяц + базовые функции. Платный тариф — безлимитные запросы и доступ к топовым моделям.

### Плюсы
- Понимает контекст всего проекта
- Может редактировать несколько файлов одновременно
- Работает с любым языком программирования

### Минусы
- Требует подписку для полноценной работы
- Потребляет много памяти

### Ссылка
[cursor.com](https://cursor.com)

### Вердикт
Лучший выбор для вайбкодинга. Если выбирать один инструмент — выбирайте Cursor.
```

### Плохой пример (не делать так):
```markdown
## Cursor

Cursor - это программа для написания кода. Она использует искусственный интеллект. AI помогает писать код. Можно скачать бесплатно. Есть платная версия.
```

## Оптимальная длина разделов

| Формат | Страниц на раздел |
|--------|-------------------|
| Гайд: один шаг | 1-2 страницы |
| Инструмент/идея | 0.5-1 страница |
| Чек-лист: категория | 0.5 страницы |
| Таблица сравнения | 1 страница |
| Введение | 1 страница |
| Заключение | 1 страница |
| Об авторе | 1 страница |
