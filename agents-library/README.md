# Коробка с субагентами

155 субагентов из набора [awesome-claude-code-subagents](https://github.com/VoltAgent/awesome-claude-code-subagents), разложенных по категориям. Лежат на хранении и **не работают**, пока их отсюда не достанешь.

## Почему они не в работе

Субагенты устроены не как скиллы. У скилла есть спящий режим: строка `disable-model-invocation: true`, и он не занимает контекст, пока не позовёшь. **У субагентов такого выключателя нет.** Всё, что лежит в `.claude/agents/`, грузится в контекст при каждом запуске.

Посчитано: 158 описаний это около 8300 токенов в каждой сессии, без возможности отключить.

Поэтому здесь и коробка. Claude заглядывает только в `.claude/agents/`, а в эту папку не смотрит. Файлы в репозитории, ничего не потеряно, контекст не тратится.

## Кто в работе сейчас

| Субагент | Зачем взяли |
|---|---|
| `debugger` | разбор падений и непонятных ошибок |
| `python-pro` | живой проект целиком на Python |
| `fastapi-developer` | бэкенд на FastAPI |

Плюс пять своих: четыре от `impeccable` и `brief-constructor` от `banana`.

## Как достать нужного

```bash
cp agents-library/КАТЕГОРИЯ/ИМЯ.md .claude/agents/
```

Например:

```bash
cp agents-library/02-language-specialists/sql-pro.md .claude/agents/
```

Заработает со следующего запуска сессии.

## Как убрать обратно

```bash
rm .claude/agents/ИМЯ.md
```

Файл останется в коробке, удаляется только рабочая копия.

## Правило

**Доставай по одному и под задачу.** Каждый вынутый агент это постоянный расход контекста, а не разовый. Взял для дела, закончил, положил обратно.

Если сомневаешься, нужен ли он, скорее всего не нужен. За целый день работы ни один из пяти уже установленных не понадобился ни разу.

## Осторожно с дублями

Многое здесь перекрывается с тем, что уже есть:

- `content-marketer`, `seo-specialist` и соседи по `08-business-product` дублируют 49 маркетинговых скиллов
- `code-reviewer` перекрывается со встроенной командой `/code-review`
- `ui-designer`, `frontend-developer` спорят с восемью дизайнерскими скиллами

Прежде чем доставать, проверь, нет ли уже скилла на ту же задачу. Скилл дешевле: он умеет спать.
