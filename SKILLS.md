# Скиллы и плагины: что включать и как

Коротко о текущем состоянии и способах им управлять.

## Текущее состояние

|         | Активно | Спит |
| ------- | ------- | ---- |
| Скиллы  | 7       | 98   |
| Плагины | 1       | 31   |

**Спящий скилл не равен выключенному.** Он на месте и вызывается по имени, но его описание не грузится в контекст, пока не позовут. Разница только в том, что Claude не подхватит его сам.

Активны сейчас: `redaktura`, `statya`, `post`, `promo`, `ux-copy`, `redpolitika`, `stop-slop`. Они оставлены потому, что срабатывают на обычные просьбы про текст.

Из плагинов включён `intelligent-compact`: он работает фоном и сохраняет пути к файлам и первопричины при автосжатии контекста.

## Как это работает

Механизм: поле `disable-model-invocation: true` в начале файла `SKILL.md`.

| Настройка                        | Вызываешь ты | Вызывает Claude | В контексте     |
| -------------------------------- | ------------ | --------------- | --------------- |
| нет поля                         | да           | да              | описание всегда |
| `disable-model-invocation: true` | да           | нет             | ничего          |

Плагины устроены иначе: у них общий выключатель на весь плагин, и выключенный не даёт ничего: ни скиллов, ни хуков, ни MCP-серверов.

## Главное: как позвать спящий скилл

**Никак специально. Просто напиши `/имя`.**

```
/impeccable        аудит и полировка интерфейса
/banana            генерация картинок
/marketing-plan    маркетинговый план
/llm-council       совет из пяти советников
/statya            статья с нуля
```

Ничего включать не нужно. Скилл подгрузится целиком в момент вызова.

## Если нужно, чтобы срабатывал сам

Убрать одну строку из `SKILL.md`:

```bash
sed -i '/^disable-model-invocation: true$/d' .claude/skills/ИМЯ/SKILL.md
```

Чтобы вернуть обратно, допиши её в блок между `---` в начале файла. Изменение подхватится со следующей сессии.

## Плагины: включить и выключить

```bash
claude plugin enable ИМЯ@claude-settings
claude plugin disable ИМЯ@claude-settings
```

Внутри сессии после этого нужен `/reload-plugins`. Чтобы состояние пережило контейнер, оно должно попасть в `.claude/settings.json`, в поле `enabledPlugins`.

Посмотреть список: `claude plugin list`.

## Что включать под задачу

| Задача                  | Что звать                                                                   |
| ----------------------- | --------------------------------------------------------------------------- |
| Текст по-русски         | уже активно, ничего не нужно                                                |
| Английский текст        | `/stop-slop`                                                                |
| Свёрстать интерфейс     | `/impeccable`, `/ui-ux-pro-max`, `/emil-design-eng`                         |
| Выбрать стиль           | `/minimalist-ui`, `/industrial-brutalist-ui`, `/apple-design`               |
| Анимация                | `/animate`, `/review-animations`                                            |
| Переделать существующее | `/redesign-existing-projects`                                               |
| Картинки                | `/banana`, `/brandkit`, `/imagegen-frontend-web`                            |
| Видео кодом             | `/remotion-video`                                                           |
| Маркетинг               | `/marketing-plan`, `/marketing-ideas`, `/cro`, `/pricing`, всего 49 скиллов |
| Тексты интерфейса       | `/ux-copy`                                                                  |
| Сложное решение         | `/llm-council`                                                              |
| Устройство агентов      | `/context-optimization`, `/memory-systems`, `/evaluation`, всего 17         |

Плагины включаются под стек: `python-skills` и `react-skills` для кода, `supabase-skills` и `mongodb-skills` для базы, `stripe-skills` для платежей, `github-dev` для работы с пул-реквестами.

## Чего не стоит включать здесь

| Плагин                                    | Причина                                                |
| ----------------------------------------- | ------------------------------------------------------ |
| `azure-tools`, `gcloud-tools`             | нужна облачная авторизация                             |
| `paper-search-tools`                      | нужен Docker                                           |
| `tavily-tools`                            | нужен API-ключ                                         |
| `ultralytics-dev`, `ultralytics-branding` | внутренние плагины про YOLO                            |
| `humanize`                                | хук запрещает длинное тире, ломает русскую типографику |
| `claude-telemetry-hooks`                  | хук на каждое событие сессии                           |

## Где что лежит

```
.claude/skills/        скиллы (89 симлинков в .agents/skills плюс свои папки)
.claude/agents/        субагенты
.claude/settings.json  маркетплейс и список плагинов
.mcp.json              MCP-серверы проекта
```

Ключи API в репозиторий не кладём. В облачных сессиях они живут в поле Environment variables в настройках окружения, локально задаются через `claude mcp add --env`.
